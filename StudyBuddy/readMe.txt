To run program locally, use below URL:

http://127.0.0.1:5000

It brings user to home page, which has two options, to sign up, and to sign in.
All login information is stored in login_data.json. If the user has made an account in sign up, login_data.json will store the information and retrieve when signing in.

Passwords are saved through hashing, ensuring information is safe.
Once signed in, the site asks user to take a test, to find the level at which the user perfoms in school subjects, and adapt accordingly. 

Then, the site brings user to a habits page, where the user will create healthy habits.
The site will then begin a routine, walking user through the habits.
