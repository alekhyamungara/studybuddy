To run program locally use below url:

http://127.0.0.1:5000

It has two options (SignUp & SignIn).
All SignUp information stored in login_data.json as a temporary data store.
If user is already signedUp? they need to use signIn option to Login in.
If user is trying to signUp same user it will return "User is already exists".
If password is incorrect user is not allowed to signIn.
